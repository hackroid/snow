# opportunities-v01 START — 滑雪机会日历＋优惠雪票（只读研究模块）

给"未来 8 周哪些周末/假日窗口值得看"和"目标雪场有哪些已核优惠票"，出候选与比较；本模块**只产候选与证据，不产行程、不下单、不提醒**。

- 方法（不变量）：`methods/method.md`——日期推导、假日/资格/渠道核法、报价与期限字段、向 planner 的交接方式。
- 官方来源表（台账）未随导出包：各场官方入口与既有研究记录需当轮另采，未采前相关字段记 unknown。
- 每批结果（变量）：`data/batches/`——当次 8 周日期、假日、价格、剩余期限都在批次里，不写成永久偏好。
- 交接：候选窗口与票条目以结构化数据交给 planner（planner-v01）；窗口被用户选定后才可成为 planner 的 spec 日期，票条目按其资格/范围/日期字段在 planner 侧复核后才可计价。

## 边界
只读公开信息；不读私有邮箱/日历/凭据；不购买、不登录、不通知、不建监控/订阅；截止临近只在结果中标注。不改 planner 既有批次、不改四控制文件、不动 Goal/全局记忆。
