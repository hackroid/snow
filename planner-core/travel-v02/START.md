## 用户主套路（保真摘要，细则以 methods/ 为准）

- 起点是 Orion 参数化搜索链接（关东出发、マイカー＋宿）：**出发日 = 第一天滑雪日**，不是前一晚。普通周末通常 1 泊，2 泊看节假日/用户年假（不查私有日历、不替用户决定请假）。
- 人数按当轮输入；价格从低到高；常选便宜的「宿おまかせ」，但非硬限制，同时支持不限定住宿条件。
- 点入具体套餐逐项核：餐食按原文（首日晚＋次日早常见但不是保证）；**默认可能无票或只含一张票，第二天起的雪票要查产品级加购价**（常远低于窗口价），不默认全程含票、也不直接只加官网票。
- 资格限制型产品（女性专用、青春/雪マジ等年龄/身份限定）单列，资格未知不当普通可订。
- Skiichiba 同套路；同商家可能在 Orion 与 Skiichiba 双平台上架，去重时注意。
- 软参考（经验值，不是过滤器）：1 人 1 泊 2 日含所需票通常 ≤30,000；2 泊 3 日通常 ≤40,000。选项少时超价也全列并标原因；unknown 不当 0、不当最便宜。
- 廉价合作民宿常不在 OTA 上架或 OTA 更贵——这是优先顺序 heuristic，不是已证事实；OTA（Agoda/Booking/Yahoo/Rakuten/一休）仍作补充，通常不含票但以具体权益为准，餐费与买票渠道都要算进总价。
- **位置表述纪律**：目标雪场与住宿本地雪场分开。住宿页写的“徒歩 X 分”指其本地雪场，不等于到目标雪场；到目标雪场的方式与季节性设施（如跨场缆车开通日）另行核，未核写 unknown。（例：目标雪场与住宿本地雪场不同、跨场设施未开时，到目标雪场需自驾——具体以当轮核实为准。）
- 停车、步行距离/是否需开到雪场、雪场停车费在输出中体现（次要项）；停车费未知不搁置整方案。保留首日取票/预约等行程依赖。

## 默认条件（方法默认，可由当轮 spec 覆盖）

- **全员成人**是默认；有儿童/学生等情形时按当轮输入另行处理。
- **每个滑雪日都需要雪票**是默认（spec 的 ticket_days_needed 默认 = 滑雪天数）；同行有人持季票或雪マジ等资格时，在 spec 里按人另行说明，那部分人不计票需求。
- **装备（租具）不是检索/筛选条件**，不按“无需租具/自带装备”过滤任何产品；装备是**结果权益字段**，逐产品记录：含/不含/可加购/unknown、范围与天数、额外金额、费用性质（可退押金/维护费/保险等）与退还条件。
- 渠道倾向（检索优先级提示，不是每产品的事实）：套餐渠道与 OTA 散订的装备包含情况逐产品核；押金等金额未核到就记 unknown，不拿倾向填数。
- 可退押金单列为“临时支付”，不混入最终消费总价；套餐里的票/租具即使不用，也不擅自从套餐价里扣减（页面明示不可减时更如此）。
