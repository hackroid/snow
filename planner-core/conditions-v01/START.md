导出恢复入口：先读本文件与 `methods/`。当前状态（status）与批次观测未随导出包，运行时按当轮输入另行给定，未给定的实时观测一律 unknown、需另采。

## 固定原则（细则以 methods/ 为准）

- **来源只用官方**：雪场官网（营业/缆车/雪量/livecam）、気象庁 JMA（预报/警报/AMeDAS）。聚合站与自媒体只作发现线索，不作状态依据。
- **五种时间严格分开**：计划开业日期 ≠ 实际开放状态；预报有发布时刻与适用时段；页面有更新时间；本方有读取时间。四者缺一不可混用——网页能打开 ≠ 状态实时。
- **摄像头**：没有影像自带时间就写 unknown，**绝不以抓取时间冒充拍摄时间**；静止画与直播流分开记。
- **季节隔离**：只认 26–27 雪季页面/数据；标题或 URL 带旧季（如 24-25、25-26）的页面不得作为本季状态，须在观测里标“旧季已排除”。
- **预测窗口**：未来 8 周是行程窗口，不是天气可预测范围。超出官方预报适用时段的日期（如 JMA 一周预报之外）一律写“无法预测、待临近复核”，不虚构雪况、不拿气候平均冒充预报。
- **安全边界**：强风/雨/停运等只报事实与“需临近复核”提示，不替用户做安全保证、不替用户决定取消或成行。
- 本项目只观测与记录：不建通知、不建定时、不发模拟提醒；刷新由用户或上层任务指令触发。

## 边界
只读官方公开信息＋本目录文件；不查私有日历、不预订不付款。（导出副本注：来源项目中的跨项目边界以各 START 的边界节为准。）
