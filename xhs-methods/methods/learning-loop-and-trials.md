# 学习闭环与试用门槛（方法）

闭环：读规格与健康状态 → 在额度内选查询 → 唯一请求入口 →
分类/去重 → 保存观测 → 匹配/通知 → 关联用户结果 → 低频提出
策略补丁 → 有限试用 → 启用或回退。

策略状态：seed/candidate → trial → active → cooldown/retired，
每步留原因与回退点。可学习面仅限查询文本、已文档化的筛选
选择、排序轮换、策略权重与复测时间；硬规则、权限、凭据、
总额度、停止/冷却政策、用户事实、执行代码与评测答案不可学。

## 探索门（exploration gates，进 trial 前先过）

账号与执行器健康；总额度预算已配置；有可用的同期基线。
探索占原额度、不另给：每个批次最多替换 1 个既有查询槽，
滚动 10 次查询中探索最多 2 次。任一请求异常即停批，本次
质量比较作废（invalid/censored），不扣被替换基线词的质量；
探索不得绕过冷却。

## 试用前必须冻结（缺一保持 candidate）

假设及适用季节/区域/角色/时间条件；唯一主要改变维度与当前
基线版本；要改善的业务指标、计算分母与观察窗口；同期可
比较基线/匹配条件与保留样本来源；效果通过阈值与误配/成本
等不可退化条件；额度内最大试用长度、停止条件与回退版本。

## 参考工程门槛与启用全条件

最低工程证据参考：≥2 个不同日期、≥3 个成功批次、≥10 条
已判唯一帖、≥2 条已核新相关、≥2 个正例来源簇。这些量化
数字只是当前方法提案的工程门槛，不是平台安全保证，也不
构成统计显著性结论。
启用须同时满足：证据引用/规则字段/基础版本与硬规则校验
通过；达到最低门槛（缺失/未读不补成已判）；预冻结指标实测
达阈值且基线比较确实可比；保留样本/新批次验证通过；非退化
条件与额度约束通过且有具体测量值；当前健康且可回退。
请求成功不等于效果成功；样本稀疏、情境不可比、全为 0 相关
或没有可比基线时，一律保持 candidate/trial。
启用后定期复核；确认误配、条件不适用或触及预设回退线则
回退，不改写过去记录。

## 抽样排序与评估分工（候选修订，2026-11-12）

代码只管身份、额度与抽样排序；语义判断归评估者。标题/
摘要启发式只产生疑似级排序信号：当前规格范围内优先、
未知其次、疑似范围外最低。它只影响抽样优先级，不保证
何时被抽中（每查询抽取数与总预算有限，低优先级帖子可
能本批或后续都未抽到）；不直接丢弃候选，不产生
exclude，不是评估证据，不得映射成评估结论或写进评估
理由。真正的 exclude 由评估者在详情全文上按当次规格
与连续原文证据判断：肯定目的地证据且与当次规格不相容
时可 exclude，与日期、角色等其他字段是否未知分开；
区域泛称、历史、否定、比较提及不构成不相容证据。
