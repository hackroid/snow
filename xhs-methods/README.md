# xhs-methods（公开候选，方法层）

与 planner-core 并列的第二个候选目录：一个「社交平台组队帖
发现」工作流的方法层，供版本化审阅。它只包含方法、规则结构、
策略模式与学习方法，不包含任何真实帖子、逐字正文、截图、用户
资料/偏好/反馈、账号信息、搜索结果、数据库或凭据；来源路径与
版本在随附的 review-only 清单中，不在本包内。

## 内容

- rules/request-and-evidence-rules.md — 请求纪律与证据纪律的
  结构（具体额度数值以运行时政策文件为准，不在本包复制）。
- methods/manual-discovery.md — 用户手动发现帖子的处理方法
  （证据编号、事实/不确定分离、反馈追加、关闭与重开）。
- methods/learning-loop-and-trials.md — 策略生命周期、试用前
  冻结清单与启用全条件（方法阈值随文）。
- strategy/strategy-patterns.md — 查询模式（占位符形式）与一条
  候选模式，均非启用状态。
- CHANGELOG.md — 本候选的变更说明。

## 依赖与恢复边界（重要）

本包依赖但不包含：请求门与正式客户端桥等执行代码、评估器、
共享状态库（额度/去重/健康均为活状态）、历史证据包。
因此本包只是方法层备份：**不能据此恢复完整系统运行**，
活状态与执行代码不在备份范围内，不作此宣称。
