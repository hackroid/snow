# 查询策略模式（占位符形式，均为种子/候选）

- 模式 A（基线种子）：「{地区} 滑雪 拼车」「{范围} 滑雪 搭子」，
  排序取最新、发布时间限一周内；少量起步，按帖子 ID 去重，
  有相关信号才读详情；核发布时间、旅行日期、角色与状态。
- 模式 B（探索种子）：当接口健康且既有策略持续低产，或
  雪场/时间/角色/季节变化时，一次只改一个主要维度替换既有
  查询槽，如「{雪场} 滑雪 搭子」「{出发圈} 滑雪 求同路」；
  不做关键词笛卡尔积。
- 模式 C（候选，未试用）：「{月份} {节假日别名} 滑雪 搭子 /
  组队」——月份与别名对应的真实日期是每批当轮变量，执行前
  按当年官方假日日历核对。来源为一条手动发现样本的方法
  提炼；推荐流可见不证明搜索可检到，启用前须走完整试用
  冻结与启用全条件。
- 解析候选（评估侧，非查询策略）：无分隔连写日期在唯一
  切分且与明示月份/假期窗口相容时可记候选日期（年份仍
  待核）；多切分成立则 unknown。此候选不授权修改执行代码。
